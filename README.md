# ColBitcoin.com

Sitio web oficial de **@ColBitcoin** — asesoría personalizada en Bitcoin para colombianos.

## Propósito

ColBitcoin es una iniciativa educativa enfocada en ayudar a colombianos y latinoamericanos a entender Bitcoin, tomar decisiones con confianza y protegerse de estafas. El sitio funciona como página de aterrizaje para atraer clientes que quieran aprender Bitcoin de forma personalizada, segura y sin depender de nadie.

## Qué ofrece el sitio

- **Asesorías 1 a 1** — sesiones personalizadas por videollamada adaptadas al nivel de cada persona
- **Calculadora de satoshis** — convierte COP y USD a satoshis en tiempo real
- **Precio de Bitcoin en vivo** — USD y COP actualizados cada 60 segundos (CoinGecko API)
- **Quiz de Bitcoin** — evalúa tu nivel con 5 preguntas y recibe una recomendación personalizada
- **Planes y precios** — Sesión única ($90.000 COP) y Plan Bitcoin Completo ($280.000 COP/mes)
- **Recursos gratuitos** — video tutoriales en YouTube sobre Bitcoin y Lightning Network
- **Faucet de 21 sats** — cupón gratuito para reclamar los primeros satoshis vía Telegram
